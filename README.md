### Tech Stack

We tackled "vehicle safety in adverse weather" by developing a "simulated multi-sensor fusion system" powered by AI. Key highlights:  
- > Sensor Fusion: Simulated Radar, LiDAR, and Camera data in fog/rain using CARLA & ROS.  
-> Edge AI: Implemented low-latency processing for real-time detection with Docker & TensorFlow Lite.  
- > ML Models: Enhanced object detection in low visibility using YOLO and Dehazing algorithms.  
- > Risk Assessment : Built an adaptive warning system with "Reinforcement Learning".  
**Node.js**,**Express.js** ,**Javascript**,**python**,**ML**
